# `event` onPlayerVoiceStart <font size="4">(server-side)</font>
!!! info "Available since version: 0.3.0"

This event is triggered when validated voice packets start arriving from a player.

## Parameters
```c++
void onPlayerVoiceStart(number player_id)
```

* `number` **player_id**: Speaking player id.

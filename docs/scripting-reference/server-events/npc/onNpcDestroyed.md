# `event` onNpcDestroyed <font size="4">(server-side)</font>
!!! info "Available since version: 0.3.0"

Triggered after a server-owned NPC is destroyed. The id is no longer valid.

## Parameters
```c++
void onNpcDestroyed(number npc_id)
```

* `number` **npc_id**: Destroyed NPC id.

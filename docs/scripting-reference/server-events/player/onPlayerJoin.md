# `event` onPlayerJoin <font size="4">(server-side)</font>
!!! info "Available since version: 0.3.0"

Triggered when a player successfully joined the server.

## Parameters
```c++
void onPlayerJoin(int player_id)
```

* `int` **player_id**: The id of the player who joined the server.

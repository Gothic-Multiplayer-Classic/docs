# `event` onPlayerWorldEnter <font size="4">(server-side)</font>
!!! info "Available since version: 0.3.0"

This event is triggered when player entered the world and was spawned in it.

## Parameters
```c++
void onPlayerWorldEnter(number player_id, string world)
```

* `number` **player_id**: The id of the player who entered the world.
* `string` **world**: The filename of the world.

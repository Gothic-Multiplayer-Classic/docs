# `event` onPlayerSpawn <font size="4">(server-side)</font>
!!! info "Available since version: 0.3.0"

This event is triggered when a player spawns (initial spawn).

## Parameters
```c++
void onPlayerSpawn(number player_id, number x, number y, number z)
```

* `number` **player_id**: Player id spawned.
* `number` **x**: X coordinate of spawn.
* `number` **y**: Y coordinate of spawn.
* `number` **z**: Z coordinate of spawn.

# `event` onPlayerStandUp <font size="4">(server-side)</font>
!!! info "Available since version: 0.3.0"

Triggered when a player stands up after being unconscious.

## Parameters
```c++
void onPlayerStandUp(number player_id)
```

* `number` **player_id**: The id of the player who stood up.

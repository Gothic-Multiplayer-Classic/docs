# `function` setDayLength <font size="4">(server-side)</font>
!!! info "Available since version: 0.3.0"

This function will set the duration of a full in-game day in milliseconds.

## Declaration
```cpp
void setDayLength(number miliseconds)
```

## Parameters
* `number` **miliseconds**: Day length in milliseconds (min 10000 ms).

# `function` destroyNpc <font size="4">(server-side)</font>
!!! info "Available since version: 0.3.0"

Destroys an NPC and cancels its queued actions.

## Declaration
```cpp
boolean destroyNpc(number npc_id)
```

## Parameters
* `number` **npc_id**: Server NPC id.
  
## Returns `boolean`
True if the NPC was destroyed.

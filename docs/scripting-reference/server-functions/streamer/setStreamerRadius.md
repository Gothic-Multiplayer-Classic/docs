# `function` setStreamerRadius <font size="4">(server-side)</font>
!!! info "Available since version: 0.3.0"

This function sets the global player streaming radius.

## Declaration
```cpp
boolean setStreamerRadius(number radius)
```

## Parameters
* `number` **radius**: Streaming radius in world units.
  
## Returns `boolean`
True if the value was accepted.

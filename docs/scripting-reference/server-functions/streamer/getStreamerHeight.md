# `function` getStreamerHeight <font size="4">(server-side)</font>
!!! info "Available since version: 0.3.0"

This function returns the global player streaming height.

## Declaration
```cpp
number getStreamerHeight()
```

## Parameters
No parameters.
  
## Returns `number`
Streaming height in world units, or 0 for unlimited.

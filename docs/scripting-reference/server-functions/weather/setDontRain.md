# `function` setDontRain <font size="4">(server-side)</font>
!!! info "Available since version: 0.3.0"

This function will enable/disable weather completely.

## Declaration
```cpp
void setDontRain(boolean toggle)
```

## Parameters
* `boolean` **toggle**: True to disable weather, false to enable it.

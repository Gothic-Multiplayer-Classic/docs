# `function` setPlayerNextLevelExp <font size="4">(server-side)</font>
!!! info "Available since version: 0.3.0"

This function will set the experience required for the player's next level.

## Declaration
```cpp
boolean setPlayerNextLevelExp(number player_id, number next_level_exp)
```

## Parameters
* `number` **player_id**: Target player id.
* `number` **next_level_exp**: Required exp for next level.
  
## Returns `boolean`
True on success.

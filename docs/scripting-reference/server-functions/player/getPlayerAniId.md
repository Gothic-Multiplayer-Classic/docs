# `function` getPlayerAniId <font size="4">(server-side)</font>
!!! info "Available since version: 0.3.0"

This function will return the last reported player animation id.

## Declaration
```cpp
number getPlayerAniId(number player_id)
```

## Parameters
* `number` **player_id**: Target player id.
  
## Returns `number`
Animation id, or -1 if unavailable.

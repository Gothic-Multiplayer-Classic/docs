# `function` removePlayerOverlay <font size="4">(server-side)</font>
!!! info "Available since version: 0.3.0"

This function will remove a specified animation overlay from the player.

## Declaration
```cpp
boolean removePlayerOverlay(number player_id, string overlay)
```

## Parameters
* `number` **player_id**: Target player id.
* `string` **overlay**: Overlay name.
  
## Returns `boolean`
True on success.

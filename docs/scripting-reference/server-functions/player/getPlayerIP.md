# `function` getPlayerIP <font size="4">(server-side)</font>
!!! info "Available since version: 0.3.0"

This function will return the player's IP address or nil if unavailable.

## Declaration
```cpp
string|nil getPlayerIP(number player_id)
```

## Parameters
* `number` **player_id**: Target player id.
  
## Returns `string|nil`
Player IP or nil.

# `function` equipHelmet <font size="4">(server-side)</font>
!!! info "Available since version: 0.3.0"

This function will equip a helmet item for the player.

## Declaration
```cpp
boolean equipHelmet(number player_id, string instance)
```

## Parameters
* `number` **player_id**: Target player id.
* `string` **instance**: Helmet item instance name.
  
## Returns `boolean`
True when the equip packet was sent.

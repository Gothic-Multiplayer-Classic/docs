# `function` getPlayerName <font size="4">(server-side)</font>
!!! info "Available since version: 0.3.0"

This function will return the player's name, or nil if unavailable.

## Declaration
```cpp
string|nil getPlayerName(number player_id)
```

## Parameters
* `number` **player_id**: Target player id.
  
## Returns `string|nil`
Player name or nil.

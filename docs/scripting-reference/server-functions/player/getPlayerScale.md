# `function` getPlayerScale <font size="4">(server-side)</font>
!!! info "Available since version: 0.3.0"

This function will return the player's model scale.

## Declaration
```cpp
{x, y, z}|nil getPlayerScale(number player_id)
```

## Parameters
* `number` **player_id**: Target player id.
  
## Returns `{x, y, z}|nil`
Scale table or nil.

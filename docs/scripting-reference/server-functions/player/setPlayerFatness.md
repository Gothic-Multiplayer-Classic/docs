# `function` setPlayerFatness <font size="4">(server-side)</font>
!!! info "Available since version: 0.3.0"

This function will set the player/NPC's model fatness.

## Declaration
```cpp
boolean setPlayerFatness(number player_id, number fatness)
```

## Parameters
* `number` **player_id**: Target player or NPC id.
* `number` **fatness**: Fatness value.
  
## Returns `boolean`
True on success.

# `function` setPlayerStrength <font size="4">(server-side)</font>
!!! info "Available since version: 0.3.0"

This function will set the player's strength attribute.

## Declaration
```cpp
boolean setPlayerStrength(number player_id, number strength)
```

## Parameters
* `number` **player_id**: Target player id.
* `number` **strength**: New strength value.
  
## Returns `boolean`
True on success.

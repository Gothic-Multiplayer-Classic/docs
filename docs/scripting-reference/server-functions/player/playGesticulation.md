# `function` playGesticulation <font size="4">(server-side)</font>
!!! info "Available since version: 0.3.0"

This function will play gesticulation animation on the player/NPC.

## Declaration
```cpp
boolean playGesticulation(number player_id)
```

## Parameters
* `number` **player_id**: Target player or NPC id.
  
## Returns `boolean`
True on success.

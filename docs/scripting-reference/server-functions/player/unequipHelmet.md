# `function` unequipHelmet <font size="4">(server-side)</font>
!!! info "Available since version: 0.3.0"

This function will unequip the player/NPC's current helmet.

## Declaration
```cpp
boolean unequipHelmet(number player_id)
```

## Parameters
* `number` **player_id**: Target player or NPC id.
  
## Returns `boolean`
True when an equipped helmet item was found and unequipped.

# `function` playAni <font size="4">(server-side)</font>
!!! info "Available since version: 0.3.0"

This function will play an animation on the player's character.

## Declaration
```cpp
boolean playAni(number player_id, string aniName)
```

## Parameters
* `number` **player_id**: Target player id.
* `string` **aniName**: Animation name (e.g. "T_STAND_2_SIT").
  
## Returns `boolean`
True on success.

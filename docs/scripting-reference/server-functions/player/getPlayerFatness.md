# `function` getPlayerFatness <font size="4">(server-side)</font>
!!! info "Available since version: 0.3.0"

This function will return the player/NPC's model fatness, or nil if unavailable.

## Declaration
```cpp
float|nil getPlayerFatness(number player_id)
```

## Parameters
* `number` **player_id**: Target player or NPC id.
  
## Returns `float|nil`
Fatness value or nil.

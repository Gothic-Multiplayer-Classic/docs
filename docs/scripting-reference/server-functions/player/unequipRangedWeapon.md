# `function` unequipRangedWeapon <font size="4">(server-side)</font>
!!! info "Available since version: 0.3.0"

This function will unequip the player's current ranged weapon.

## Declaration
```cpp
boolean unequipRangedWeapon(number player_id)
```

## Parameters
* `number` **player_id**: Target player id.
  
## Returns `boolean`
True when an equipped ranged weapon was found and unequipped.

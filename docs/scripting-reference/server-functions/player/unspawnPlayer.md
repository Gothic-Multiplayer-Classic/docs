# `function` unspawnPlayer <font size="4">(server-side)</font>
!!! info "Available since version: 0.3.0"

This function will unspawn the player without disconnecting him.

## Declaration
```cpp
boolean unspawnPlayer(number player_id)
```

## Parameters
* `number` **player_id**: Target player or NPC id.
  
## Returns `boolean`
True on success.

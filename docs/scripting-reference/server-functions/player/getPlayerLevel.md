# `function` getPlayerLevel <font size="4">(server-side)</font>
!!! info "Available since version: 0.3.0"

This function will return the player/NPC's level, or nil if unavailable.

## Declaration
```cpp
number|nil getPlayerLevel(number player_id)
```

## Parameters
* `number` **player_id**: Target player or NPC id.
  
## Returns `number|nil`
Level or nil.

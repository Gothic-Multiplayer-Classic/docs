# `function` getPlayerMana <font size="4">(server-side)</font>
!!! info "Available since version: 0.3.0"

This function will return the player's current mana, or nil if unavailable.

## Declaration
```cpp
number|nil getPlayerMana(number player_id)
```

## Parameters
* `number` **player_id**: Target player id.
  
## Returns `number|nil`
Mana value or nil.

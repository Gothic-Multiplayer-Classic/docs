# `function` setPlayerDexterity <font size="4">(server-side)</font>
!!! info "Available since version: 0.3.0"

This function will set the player/NPC's dexterity attribute.

## Declaration
```cpp
boolean setPlayerDexterity(number player_id, number dexterity)
```

## Parameters
* `number` **player_id**: Target player or NPC id.
* `number` **dexterity**: New dexterity value.
  
## Returns `boolean`
True on success.

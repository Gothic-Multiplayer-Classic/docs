# `function` getPlayersStreamingPlayer <font size="4">(server-side)</font>
!!! info "Available since version: 0.3.0"

This function will return the list of players currently observing the given player or NPC.

## Declaration
```cpp
{...} getPlayersStreamingPlayer(number player_id)
```

## Parameters
* `number` **player_id**: Target player or NPC id.
  
## Returns `{...}`
Array of player ids.

# `function` setVoiceRange <font size="4">(server-side)</font>
!!! info "Available since version: 0.3.0"

This function changes the proximity range and assigns it to every player.

## Declaration
```cpp
boolean setVoiceRange(number range)
```

## Parameters
* `number` **range**: Voice range in game units; must be non-negative.
  
## Returns `boolean`
True when the range was accepted.

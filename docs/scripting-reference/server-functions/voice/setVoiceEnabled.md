# `function` setVoiceEnabled <font size="4">(server-side)</font>
!!! info "Available since version: 0.3.0"

This function enables or disables the server voice chat system for every player.

## Declaration
```cpp
boolean setVoiceEnabled(boolean enabled)
```

## Parameters
* `boolean` **enabled**: Whether voice chat is enabled globally.
  
## Returns `boolean`
True when the setting was applied.

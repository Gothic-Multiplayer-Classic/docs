# `function` getVoiceEnabled <font size="4">(server-side)</font>
!!! info "Available since version: 0.3.0"

This function returns whether the server voice chat system is enabled.

## Declaration
```cpp
boolean getVoiceEnabled()
```

## Parameters
No parameters.
  
## Returns `boolean`
True when voice chat is enabled globally.

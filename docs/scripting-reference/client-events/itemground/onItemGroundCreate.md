# `event` onItemGroundCreate <font size="4">(client-side)</font>
!!! info "Available since version: 0.3.0"

This event is triggered when a server-side ground item is created for the client.

## Parameters
```c++
void onItemGroundCreate(ItemGround itemGround)
```

* `ItemGround` **itemGround**: Ground item object.

# `event` onItemGroundDestroy <font size="4">(client-side)</font>
!!! info "Available since version: 0.3.0"

This event is triggered when a server-side ground item is destroyed for the client.

## Parameters
```c++
void onItemGroundDestroy(ItemGround itemGround)
```

* `ItemGround` **itemGround**: Ground item object.

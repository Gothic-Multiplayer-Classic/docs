# `event` onPlayerChangePing <font size="4">(client-side)</font>
!!! info "Available since version: 0.3.0"

This event is triggered when the client receives a ping update for a player.

## Parameters
```c++
void onPlayerChangePing(number id, number ping)
```

* `number` **id**: The id of the player.
* `number` **ping**: The player's ping.

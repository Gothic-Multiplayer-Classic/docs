# `event` onPlayerDestroy <font size="4">(client-side)</font>
!!! info "Available since version: 0.3.0"

This event is triggered when a local player object is destroyed.

## Parameters
```c++
void onPlayerDestroy(number player_id)
```

* `number` **player_id**: The local player id.

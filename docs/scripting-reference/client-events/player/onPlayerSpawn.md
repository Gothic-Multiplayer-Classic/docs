# `event` onPlayerSpawn <font size="4">(client-side)</font>
!!! info "Available since version: 0.3.0"

This event is triggered when a player is spawned into the world.

## Parameters
```c++
void onPlayerSpawn(number id)
```

* `number` **id**: The id of the spawned player.

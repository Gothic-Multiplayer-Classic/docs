# `event` onVoiceChannelChange <font size="4">(client-side)</font>
!!! info "Available since version: 0.3.0"

This event is triggered when the local player changes voice channels.

## Parameters
```c++
void onVoiceChannelChange(string old_channel, string new_channel)
```

* `string` **old_channel**: Previous channel name.
* `string` **new_channel**: New channel name.

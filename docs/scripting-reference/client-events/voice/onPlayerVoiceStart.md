# `event` onPlayerVoiceStart <font size="4">(client-side)</font>
!!! info "Available since version: 0.3.0"

This event is triggered when a remote player starts speaking.

## Parameters
```c++
void onPlayerVoiceStart(number player_id)
```

* `number` **player_id**: Speaking player id.

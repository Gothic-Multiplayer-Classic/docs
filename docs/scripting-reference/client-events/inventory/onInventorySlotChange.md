# `event` onInventorySlotChange <font size="4">(client-side)</font>
!!! info "Available since version: 0.3.0"

This event is triggered when the selected inventory slot changes.

## Parameters
```c++
void onInventorySlotChange(number from, number to)
```

* `number` **from**: Previous slot number.
* `number` **to**: Current slot number.

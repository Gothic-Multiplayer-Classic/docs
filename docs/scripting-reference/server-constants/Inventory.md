# `constants` Inventory <font size="4">(server-side)</font>

| Name         | Description                          |
| :----------: | :----------------------------------- |
| `EQUIP_SLOT_GENERIC` | Selects the equipment category of the item; rings use an available ring slot. |
| `EQUIP_SLOT_ARMOR` | Selects the armor slot. |
| `EQUIP_SLOT_MELEE_WEAPON` | Selects the melee weapon slot. |
| `EQUIP_SLOT_RANGED_WEAPON` | Selects the ranged weapon slot. |
| `EQUIP_SLOT_HELMET` | Selects the helmet slot. |
| `EQUIP_SLOT_SHIELD` | Selects the shield slot. |
| `EQUIP_SLOT_AMULET` | Selects the amulet slot. |
| `EQUIP_SLOT_BELT` | Selects the belt slot. |
| `EQUIP_SLOT_RING_LEFT` | Selects the first ring slot, independently of the other ring's item instance. |
| `EQUIP_SLOT_RING_RIGHT` | Selects the second ring slot, independently of the other ring's item instance. |

# `function` isConsoleOpen <font size="4">(client-side)</font>
!!! info "Available since version: 0.3.0"

This function will check whether the Gothic console is open.

## Declaration
```cpp
boolean isConsoleOpen()
```

## Parameters
No parameters.
  
## Returns `boolean`
True when the console is visible.

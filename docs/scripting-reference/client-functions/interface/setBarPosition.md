# `function` setBarPosition <font size="4">(client-side)</font>
!!! info "Available since version: 0.3.0"

This function will set a Gothic HUD status bar position in virtual coordinates.

## Declaration
```cpp
boolean setBarPosition(number hud_type, number x, number y)
```

## Parameters
* `number` **hud_type**: Status bar HUD type constant. For more information, see [HUD Constants](../../client-constants/HUD.md).
* `number` **x**: X position.
* `number` **y**: Y position.
  
## Returns `boolean`
True on success.

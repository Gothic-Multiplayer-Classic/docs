# `function` setBarSize <font size="4">(client-side)</font>
!!! info "Available since version: 0.3.0"

This function will set a Gothic HUD status bar size in virtual coordinates.

## Declaration
```cpp
boolean setBarSize(number hud_type, number width, number height)
```

## Parameters
* `number` **hud_type**: Status bar HUD type constant. For more information, see [HUD Constants](../../client-constants/HUD.md).
* `number` **width**: Width.
* `number` **height**: Height.
  
## Returns `boolean`
True on success.

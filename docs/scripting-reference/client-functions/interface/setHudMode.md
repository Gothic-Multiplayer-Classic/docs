# `function` setHudMode <font size="4">(client-side)</font>
!!! info "Available since version: 0.3.0"

This function will set the Gothic HUD display mode.

## Declaration
```cpp
boolean setHudMode(number hud_type, number mode)
```

## Parameters
* `number` **hud_type**: HUD type constant. For more information, see [HUD Constants](../../client-constants/HUD.md).
* `number` **mode**: HUD mode constant from the same table.
  
## Returns `boolean`
True on success.

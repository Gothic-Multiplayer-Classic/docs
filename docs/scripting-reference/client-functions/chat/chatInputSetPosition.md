# `function` chatInputSetPosition <font size="4">(client-side)</font>
!!! info "Available since version: 0.3.0"

This function changes the chat input position in virtual screen units.

## Declaration
```cpp
void chatInputSetPosition(number x, number y)
```

## Parameters
* `number` **x**: X position.
* `number` **y**: Y position.

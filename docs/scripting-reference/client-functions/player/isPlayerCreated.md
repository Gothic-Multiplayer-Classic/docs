# `function` isPlayerCreated <font size="4">(client-side)</font>
!!! info "Available since version: 0.3.0"

This function will check whether a player or client NPC object exists.

## Declaration
```cpp
boolean isPlayerCreated(number player_id)
```

## Parameters
* `number` **player_id**: Target player or client NPC id.
  
## Returns `boolean`
True when the object exists.

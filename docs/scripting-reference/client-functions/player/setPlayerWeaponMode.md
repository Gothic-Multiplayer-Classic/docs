# `function` setPlayerWeaponMode <font size="4">(client-side)</font>
!!! info "Available since version: 0.3.0"

This function will set the player/npc weapon mode for all players.

## Declaration
```cpp
void setPlayerWeaponMode(number player_id, number weapon_mode)
```

## Parameters
* `number` **player_id**: Target player id.
* `number` **weapon_mode**: Weapon mode constant.

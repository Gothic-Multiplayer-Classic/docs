# `function` equipRangedWeapon <font size="4">(client-side)</font>
!!! info "Available since version: 0.3.0"

This function will equip a ranged weapon for a player or NPC.

## Declaration
```cpp
boolean equipRangedWeapon(number player_id, string instance)
```

## Parameters
* `number` **player_id**: Target player or client NPC id.
* `string` **instance**: Ranged weapon item instance name.
  
## Returns `boolean`
True on success.

# `function` setPlayerCollision <font size="4">(client-side)</font>
!!! info "Available since version: 0.3.0"

This function will enable or disable collision and physics for a player or NPC.

## Declaration
```cpp
boolean setPlayerCollision(number player_id, boolean enabled)
```

## Parameters
* `number` **player_id**: Target player or client NPC id.
* `boolean` **enabled**: Collision state.
  
## Returns `boolean`
True on success.

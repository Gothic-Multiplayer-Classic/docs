# `function` setPlayerOnFloor <font size="4">(client-side)</font>
!!! info "Available since version: 0.3.0"

This function will place a player or NPC on the floor at its current position.

## Declaration
```cpp
boolean setPlayerOnFloor(number player_id)
```

## Parameters
* `number` **player_id**: Target player or client NPC id.
  
## Returns `boolean`
True on success.

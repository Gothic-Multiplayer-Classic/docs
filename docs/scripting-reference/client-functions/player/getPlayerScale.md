# `function` getPlayerScale <font size="4">(client-side)</font>
!!! info "Available since version: 0.3.0"

Get a player's model scale.

## Declaration
```cpp
{x, y, z}|nil getPlayerScale(number player_id)
```

## Parameters
* `number` **player_id**: Target player id.
  
## Returns `{x, y, z}|nil`
Player scale or nil.

# `function` unspawnNpc <font size="4">(client-side)</font>
!!! info "Available since version: 0.3.0"

This function will unspawn a client NPC from the world.

## Declaration
```cpp
boolean unspawnNpc(number npc_id)
```

## Parameters
* `number` **npc_id**: Internal npc id.
  
## Returns `boolean`
True on success.

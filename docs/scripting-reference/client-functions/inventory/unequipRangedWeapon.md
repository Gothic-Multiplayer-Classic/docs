# `function` unequipRangedWeapon <font size="4">(client-side)</font>
!!! info "Available since version: 0.3.0"

This function will unequip the current ranged weapon from a player or NPC.

## Declaration
```cpp
boolean unequipRangedWeapon(number player_id)
```

## Parameters
* `number` **player_id**: Target player or client NPC id.
  
## Returns `boolean`
True when a ranged weapon was equipped and unequipped.

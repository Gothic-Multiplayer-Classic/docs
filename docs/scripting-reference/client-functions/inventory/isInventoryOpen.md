# `function` isInventoryOpen <font size="4">(client-side)</font>
!!! info "Available since version: 0.3.0"

This function will check whether the local player's inventory is open.

## Declaration
```cpp
boolean isInventoryOpen()
```

## Parameters
No parameters.
  
## Returns `boolean`
True when the inventory is open.

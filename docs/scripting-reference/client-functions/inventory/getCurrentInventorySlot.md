# `function` getCurrentInventorySlot <font size="4">(client-side)</font>
!!! info "Available since version: 0.3.0"

This function will return the local player's currently selected inventory slot.

## Declaration
```cpp
number|nil getCurrentInventorySlot()
```

## Parameters
No parameters.
  
## Returns `number|nil`
Current inventory slot, starting from 0, or nil if unavailable.

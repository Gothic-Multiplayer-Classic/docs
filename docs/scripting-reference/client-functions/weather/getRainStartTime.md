# `function` getRainStartTime <font size="4">(client-side)</font>
!!! info "Available since version: 0.3.0"

This function will return the configured sky weather time when it starts raining/snowing.

## Declaration
```cpp
{hour, min} getRainStartTime()
```

## Parameters
No parameters.
  
## Returns `{hour, min}`
The sky weather raining start time.

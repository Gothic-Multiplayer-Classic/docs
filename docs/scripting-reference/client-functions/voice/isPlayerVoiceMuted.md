# `function` isPlayerVoiceMuted <font size="4">(client-side)</font>
!!! info "Available since version: 0.3.0"

This function checks whether a remote player's voice is muted locally.

## Declaration
```cpp
boolean isPlayerVoiceMuted(number player_id)
```

## Parameters
* `number` **player_id**: Player id.
  
## Returns `boolean`
True when the player is muted.

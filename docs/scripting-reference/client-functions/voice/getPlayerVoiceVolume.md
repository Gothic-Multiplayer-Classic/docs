# `function` getPlayerVoiceVolume <font size="4">(client-side)</font>
!!! info "Available since version: 0.3.0"

This function returns a remote player's local volume multiplier.

## Declaration
```cpp
number getPlayerVoiceVolume(number player_id)
```

## Parameters
* `number` **player_id**: Player id.
  
## Returns `number`
Multiplier from 0.0 to 1.0.

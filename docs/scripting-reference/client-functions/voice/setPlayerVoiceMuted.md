# `function` setPlayerVoiceMuted <font size="4">(client-side)</font>
!!! info "Available since version: 0.3.0"

This function mutes or unmutes a remote player locally.

## Declaration
```cpp
boolean setPlayerVoiceMuted(number player_id, boolean muted)
```

## Parameters
* `number` **player_id**: Player id.
* `boolean` **muted**: New mute state.
  
## Returns `boolean`
True when the player id was valid.

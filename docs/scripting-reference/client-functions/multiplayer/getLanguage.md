# `function` getLanguage <font size="4">(client-side)</font>
!!! info "Available since version: 0.3.0"

This function will return the language currently used by the client.

## Declaration
```cpp
number getLanguage()
```

## Parameters
No parameters.
  
## Returns `number`
Language index selected in the client settings.

# `function` toggleDrawWaynet <font size="4">(client-side)</font>
!!! info "Available since version: 0.3.0"

This function will enable/disable waynet rendering.

## Declaration
```cpp
void toggleDrawWaynet(boolean enabled)
```

## Parameters
* `boolean` **enabled**: True to render waynet, false to disable.

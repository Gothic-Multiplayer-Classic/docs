# `function` getCursorSize <font size="4">(client-side)</font>
!!! info "Available since version: 0.3.0"

This function will return the cursor size in virtual (screen-scaled) units.

## Declaration
```cpp
{x, y} getCursorSize()
```

## Parameters
No parameters.
  
## Returns `{x, y}`
Cursor width and height.

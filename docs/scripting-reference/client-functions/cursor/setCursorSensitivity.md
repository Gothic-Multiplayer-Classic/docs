# `function` setCursorSensitivity <font size="4">(client-side)</font>
!!! info "Available since version: 0.3.0"

Sets the cursor movement sensitivity.

## Declaration
```cpp
boolean setCursorSensitivity(number sensitivity)
```

## Parameters
* `number` **sensitivity**: Cursor sensitivity multiplier.
  
## Returns `boolean`
True on success.

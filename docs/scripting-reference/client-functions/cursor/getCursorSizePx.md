# `function` getCursorSizePx <font size="4">(client-side)</font>
!!! info "Available since version: 0.3.0"

This function will return the cursor size in pixel units.

## Declaration
```cpp
{x, y} getCursorSizePx()
```

## Parameters
No parameters.
  
## Returns `{x, y}`
Cursor width and height in pixels.

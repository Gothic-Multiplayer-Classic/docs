# `function` setCursorSize <font size="4">(client-side)</font>
!!! info "Available since version: 0.3.0"

Sets the cursor size in virtual (screen-scaled) units.

## Declaration
```cpp
boolean setCursorSize(number width, number height)
```

## Parameters
* `number` **width**: Cursor width.
* `number` **height**: Cursor height.
  
## Returns `boolean`
True on success.

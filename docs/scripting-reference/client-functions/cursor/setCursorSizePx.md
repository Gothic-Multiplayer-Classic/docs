# `function` setCursorSizePx <font size="4">(client-side)</font>
!!! info "Available since version: 0.3.0"

This function will set the cursor size in pixel units.

## Declaration
```cpp
void setCursorSizePx(number width, number height)
```

## Parameters
* `number` **width**: Cursor width in pixels.
* `number` **height**: Cursor height in pixels.

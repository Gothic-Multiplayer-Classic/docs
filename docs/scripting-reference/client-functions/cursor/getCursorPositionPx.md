# `function` getCursorPositionPx <font size="4">(client-side)</font>
!!! info "Available since version: 0.3.0"

This function will return the current cursor position in pixel coordinates.

## Declaration
```cpp
{x, y} getCursorPositionPx()
```

## Parameters
No parameters.
  
## Returns `{x, y}`
X and Y position in pixels.

# `function` isScriptLogicalKeyEnabled <font size="4">(client-side)</font>
!!! info "Available since version: 0.3.0"

This function will check whether a Gothic logical game action is enabled for Lua input polling.

## Declaration
```cpp
boolean isScriptLogicalKeyEnabled(number key)
```

## Parameters
* `number` **key**: The logical game action code to check. For more information about key codes, see [Logical Key
  
## Returns `boolean`
True for a valid input enabled for script polling.

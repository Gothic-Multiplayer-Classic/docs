# `function` isControlsDisabled <font size="4">(client-side)</font>
!!! info "Available since version: 0.3.0"

This function will check whether default game actions are disabled.

## Declaration
```cpp
boolean isControlsDisabled()
```

## Parameters
No parameters.
  
## Returns `boolean`
True when disabled, otherwise false.

# `function` disableControls <font size="4">(client-side)</font>
!!! info "Available since version: 0.3.0"

This function will enable or disable default game actions that are bound to keys.

## Declaration
```cpp
boolean disableControls(boolean disabled)
```

## Parameters
* `boolean` **disabled**: True to disable default game controls; false to enable.
  
## Returns `boolean`
True on success.

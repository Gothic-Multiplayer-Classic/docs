# `function` disableControls <font size="4">(client-side)</font>
!!! info "Available since version: 0.3.0"

Disable/enable default game actions that are bound to keys.

## Declaration
```cpp
boolean disableControls(boolean true)
```

## Parameters
* `boolean` **true**: when you want to disable game keys, otherwise false.
  
## Returns `boolean`
True on success.

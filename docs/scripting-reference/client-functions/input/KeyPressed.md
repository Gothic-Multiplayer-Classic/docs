# `function` keyPressed <font size="4">(client-side)</font>
!!! info "Available since version: 0.3.0"

This function will check whether the specified keyboard key is pressed.

## Declaration
```cpp
boolean keyPressed(number key)
```

## Parameters
* `number` **key**: The key code to check. For more information about key codes, see [Key Constants](../../client-constants/Key.md).
  
## Returns `boolean`
True if the key is currently pressed, false otherwise.

# `function` getNextLevelExp <font size="4">(client-side)</font>
!!! info "Available since version: 0.3.0"

This function will return the current experience required for the hero's next level, or nil if unavailable.

## Declaration
```cpp
number|nil getNextLevelExp()
```

## Parameters
No parameters.
  
## Returns `number|nil`
Next level exp or nil.

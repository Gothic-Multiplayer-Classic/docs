# `function` getExp <font size="4">(client-side)</font>
!!! info "Available since version: 0.3.0"

This function will return the hero's current experience point amount, or nil if unavailable.

## Declaration
```cpp
number|nil getExp()
```

## Parameters
No parameters.
  
## Returns `number|nil`
Exp value or nil.

# `function` setNextLevelExp <font size="4">(client-side)</font>
!!! info "Available since version: 0.3.0"

Set the experience required for the player's next level.

## Declaration
```cpp
bool setNextLevelExp(int next_level_exp)
```

## Parameters
* `int` **next_level_exp**: Required exp for next level.
  
## Returns `bool`
True on success.

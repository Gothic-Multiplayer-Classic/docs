# `function` getLearnPoints <font size="4">(client-side)</font>
!!! info "Available since version: 0.3.0"

This function will return the hero's current learn points, or nil if unavailable.

## Declaration
```cpp
number|nil getLearnPoints()
```

## Parameters
No parameters.
  
## Returns `number|nil`
Learn points or nil.

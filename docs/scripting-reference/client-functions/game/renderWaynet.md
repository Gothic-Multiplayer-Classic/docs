# `function` renderWaynet <font size="4">(client-side)</font>
!!! info "Available since version: 0.3.0"

Enable or disable waynet rendering (debug view).

## Declaration
```cpp
void renderWaynet(boolean enabled)
```

## Parameters
* `boolean` **enabled**: True to render waynet, false to disable.

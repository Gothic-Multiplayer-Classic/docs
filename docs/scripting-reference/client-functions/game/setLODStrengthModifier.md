# `function` setLODStrengthModifier <font size="4">(client-side)</font>

This function will set the global progressive mesh LOD strength modifier.

## Declaration
```cpp
void setLODStrengthModifier(number modifier)
```

## Parameters
* `number` **modifier**: LOD strength modifier.

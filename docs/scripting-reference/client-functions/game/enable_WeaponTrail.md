# `function` enable_WeaponTrail <font size="4">(client-side)</font>
!!! info "Available since version: 0.3.0"

This function will enable or disable melee weapon trails.

## Declaration
```cpp
void enable_WeaponTrail(boolean enabled)
```

## Parameters
* `boolean` **enabled**: True to show weapon trails.

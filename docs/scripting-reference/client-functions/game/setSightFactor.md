# `function` setSightFactor <font size="4">(client-side)</font>
!!! info "Available since version: 0.3.0"

This function will set the Gothic view distance scalability factor.

## Declaration
```cpp
boolean setSightFactor(number factor)
```

## Parameters
* `number` **factor**: Sight factor, clamped to 0.02 - 5.0.
  
## Returns `boolean`
True on success.

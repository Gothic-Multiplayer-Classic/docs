# `function` enable_MunitionTrail <font size="4">(client-side)</font>
!!! info "Available since version: 0.3.0"

This function will enable or disable arrow and bolt trails.

## Declaration
```cpp
void enable_MunitionTrail(boolean enabled)
```

## Parameters
* `boolean` **enabled**: True to show munition trails.

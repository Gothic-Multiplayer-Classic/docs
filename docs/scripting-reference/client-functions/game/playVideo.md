# `function` playVideo <font size="4">(client-side)</font>
!!! info "Available since version: 0.3.0"

This function will play a BIK video from Gothic's _Work\Data\Video path.

## Declaration
```cpp
boolean playVideo(string file_name)
```

## Parameters
* `string` **file_name**: BIK file name, e.g. "Intro.bik".
  
## Returns `boolean`
True when Gothic accepted the video.

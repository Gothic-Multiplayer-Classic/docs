# `function` setTime <font size="4">(client-side)</font>
!!! info "Available since version: 0.3.0"

This function will set the in-game world time (hour, minute).

## Declaration
```cpp
boolean setTime(number hour, number minute)
```

## Parameters
* `number` **hour**: Hour component.
* `number` **minute**: Minute component.
  
## Returns `boolean`
True on success.

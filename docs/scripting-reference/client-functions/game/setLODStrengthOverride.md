# `function` setLODStrengthOverride <font size="4">(client-side)</font>
!!! info "Available since version: 0.3.0"

This function will set the global progressive mesh LOD strength override.

Use -1 to use mesh values. Use 0 to disable LOD.

## Declaration
```cpp
void setLODStrengthOverride(number strength)
```

## Parameters
* `number` **strength**: LOD strength override.

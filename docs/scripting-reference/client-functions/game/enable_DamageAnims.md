# `function` enable_DamageAnims <font size="4">(client-side)</font>
!!! info "Available since version: 0.3.0"

This function will enable or disable Gothic damage animations for non-local NPCs.

## Declaration
```cpp
void enable_DamageAnims(boolean enabled)
```

## Parameters
* `boolean` **enabled**: True to allow damage animations.

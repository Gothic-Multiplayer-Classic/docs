# `function` getFpsRate <font size="4">(client-side)</font>
!!! info "Available since version: 0.3.0"

This function will return the current frame rate estimate.

## Declaration
```cpp
number getFpsRate()
```

## Parameters
No parameters.
  
## Returns `number`
Frames per second, or 0 if unavailable.

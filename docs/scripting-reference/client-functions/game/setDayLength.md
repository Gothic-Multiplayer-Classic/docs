# `function` setDayLength <font size="4">(client-side)</font>
!!! info "Available since version: 0.3.0"

This function will set the duration of an in-game day in milliseconds.

## Declaration
```cpp
boolean setDayLength(number miliseconds)
```

## Parameters
* `number` **miliseconds**: Day length in milliseconds (min 10000 ms).
  
## Returns `boolean`
True on success.

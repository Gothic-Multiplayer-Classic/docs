# `function` setBloodMode <font size="4">(client-side)</font>
!!! info "Available since version: 0.3.0"

This function will set the Gothic blood rendering mode.

Blood modes: 0 none, 1 particles, 2 decals, 3 trails, 4 amplification.

## Declaration
```cpp
boolean setBloodMode(number mode)
```

## Parameters
* `number` **mode**: Blood mode.
  
## Returns `boolean`
True on success.

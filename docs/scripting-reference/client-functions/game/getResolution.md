# `function` getResolution <font size="4">(client-side)</font>
!!! info "Available since version: 0.3.0"

This function will return the current game resolution.

## Declaration
```cpp
{x, y} getResolution()
```

## Parameters
No parameters.
  
## Returns `{x, y}`
Table containing width and height.

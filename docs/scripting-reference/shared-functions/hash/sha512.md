# `function` sha512 <font size="4">(shared-side)</font>
!!! info "Available since version: 0.3.0"

This function will calculate the SHA-512 hash of a string and return it as hex.

## Declaration
```cpp
string sha512(string input)
```

## Parameters
* `string` **input**: Input text to hash.
  
## Returns `string`
Hexadecimal hash string.

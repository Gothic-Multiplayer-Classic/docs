# `function` getRealTime <font size="4">(shared-side)</font>
!!! info "Available since version: 0.3.0"

## Declaration
```cpp
{hour, minute, second} getRealTime()
```

## Parameters
No parameters.
  
## Returns `{hour, minute, second}`
Table containing local time components.

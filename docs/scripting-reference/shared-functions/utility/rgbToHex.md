# `function` rgbToHex <font size="4">(shared-side)</font>
!!! info "Available since version: 0.3.0"

This function will convert RGB components to a lowercase hex color string.

## Declaration
```cpp
string rgbToHex(number r, number g, number b)
```

## Parameters
* `number` **r**: Red component (0-255).
* `number` **g**: Green component (0-255).
* `number` **b**: Blue component (0-255).
  
## Returns `string`
Lowercase hexadecimal representation.

# `function` LOG_INFO <font size="4">(shared-side)</font>
!!! info "Available since version: 0.3.0"

Logs a message with INFO severity.

Informational messages describe normal application behavior and
important runtime events.

## Declaration
```cpp
void LOG_INFO(string text)
```

## Parameters
* `string` **text**: Message text, may contain format specifiers.

# `function` getDistance3d <font size="4">(shared-side)</font>
!!! info "Available since version: 0.3.0"

This function returns the 3d distance between two points.

## Declaration
```cpp
number getDistance3d(number x1, number y1, number z1, number x2, number y2, number z2)
```

## Parameters
* `number` **x1**: The position on X axis of the first point.
* `number` **y1**: The position on Y axis of the first point.
* `number` **z1**: The position on Z axis of the first point.
* `number` **x2**: The position on X axis of the second point.
* `number` **y2**: The position on Y axis of the second point.
* `number` **z2**: The position on Z axis of the second point.
  
## Returns `number`
The distance between the two points.

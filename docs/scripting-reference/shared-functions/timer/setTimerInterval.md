# `function` setTimerInterval <font size="4">(shared-side)</font>
!!! info "Available since version: 0.3.0"

This function will set the interval (in milliseconds) of an existing timer.

## Declaration
```cpp
void setTimerInterval(number timer_id, number interval)
```

## Parameters
* `number` **timer_id**: Timer ID returned by setTimer.
* `number` **interval**: New interval in milliseconds.
